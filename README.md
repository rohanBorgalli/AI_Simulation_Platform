# 🧠 SAKEC End-to-End AI, ML, DL, GenAI, RAG & Agentic AI Virtual Simulation Platform

**Developed by Dr. Rohan Borgalli, Shah & Anchor Kutchhi Engineering College, Chembur**

## Overview
A complete, production-ready educational simulation platform built with **Streamlit** and **FastAPI** to train students, researchers, and faculty across 6 core modules:
1. **AI, Machine Learning & Deep Learning** (Live MLP Decision Boundary & Loss Curve Visualizer)
2. **NLP & Dense Vector Embeddings** (TF-IDF vs. 384-D Embeddings + 2D/3D PCA Projector)
3. **Vector Database Mechanics** (Cosine Similarity, Dot Product, and Euclidean L2 Distance Calculator + Pairwise Heatmap)
4. **LLMs & Prompt Engineering** (Live Softmax Temperature Scaling + Zero-Shot, Few-Shot & Chain-of-Thought Lab)
5. **Retrieval-Augmented Generation (RAG)** (5-Stage Visual Pipeline on Live PDFs: Sliding-Window Chunking, Embedding, ChromaDB Indexing, Top-K Retrieval & Grounded Synthesis)
6. **Agentic AI & ReAct Tool Calling** (Interactive `Thought -> Action -> Observation -> Final Answer` Loop)

## Quick Start
### Windows
Double-click `run_platform.bat` or run:
```bash
pip install -r requirements.txt
streamlit run app.py
```

### Linux / macOS
```bash
chmod +x run_platform.sh
./run_platform.sh
```
